# Fix: Dictionary as Library sub-tab

## Problem
Dictionary is currently a filter chip alongside Words/Idioms/etc. It should be a **sub-tab** that switches to a completely different view (dictionary search), not a chip that filters the same list.

## Current state
- Dict is a `<button class="chip" data-filter="dict">` inside the Library chips
- Clicking it hides vocab-list and shows `#dict-view` — functionally correct but feels like a chip, not a tab

## Fix

### 1. HTML: Split chips into two rows — filters + Dict tab
In `index.html` `#view-vocab`:
- Remove the Dict chip from the filter chips row
- Add a separate sub-tab bar below the filters: `[Words] [⭐ Bookmarks] [💬 Idioms] [🔗 Collocations] [📖 Stories] [💡 Tips] [🧩 Quizzes]` then a divider/gap, then `[📖 Dict]` as a distinct sub-tab button
- Use a new CSS class `.lib-tabs` for the Dict sub-tab row (distinct from `.chips`)

```html
<div class="chips">
  <button class="chip chip-on" data-filter="all">Words</button>
  ...other filters...
</div>
<div class="lib-tabs">
  <button class="lib-tab" data-lib-tab="content">📘 Content</button>
  <button class="lib-tab" data-lib-tab="dict">📖 Dictionary</button>
</div>
```

Wait — this is overcomplicating it. The simplest approach: keep Dict as a chip but style it differently and use a separate toggle mechanism (like Profile's `data-dtab`).

### Revised: Use `data-dtab` pattern (same as Profile)

**HTML** (`index.html`):
- Move Dict chip to its own row using a new `.lib-dtab` class
- Keep existing filter chips as-is

```html
<div class="chips">
  <button class="chip chip-on" data-filter="all">Words</button>
  ...other filters...
</div>
<div class="chips lib-dtab">
  <button class="chip chip-on" data-lib-tab="content">📘 Content</button>
  <button class="chip" data-lib-tab="dict">📖 Dictionary</button>
</div>
```

**JS** (`app.js`):
- Add `data-lib-tab` handler that toggles between content view (vocab-list + search + more + empty) and dict view (`#dict-view`)
- When "Content" tab is active: show vocab elements, call `loadVocab(true)`
- When "Dictionary" tab is active: hide vocab elements, show dict-view, call `loadDictionary()`
- Remove the dict filter from the `data-filter` handler (it shouldn't be there anymore)

**CSS** (`styles.css`):
- `.lib-dtab { margin-top: 8px; }` — slight spacing from the filter chips

### Files
1. `internal/app/webapp/index.html` — remove Dict from filter chips, add lib-dtab row
2. `internal/app/webapp/app.js` — add `data-lib-tab` handler, remove dict from `data-filter` handler
3. `internal/app/webapp/styles.css` — `.lib-dtab` spacing
